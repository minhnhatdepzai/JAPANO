Sau khi copy patch đè vào project, chạy theo thứ tự:

1) Chạy 1 lần để kéo model Ollama 7B:
PULL_OLLAMA_7B_WINDOWS.bat

2) Chạy 1 lần để cập nhật .env.server:
UPDATE_AI_CONFIG_WINDOWS.bat

3) Terminal 1 - Backend:
cd /d C:\JAPANO_EAS\japano-fashion-ai-v26-eas-development-build
npm run start-server

4) Terminal 2 - Expo development build:
cd /d C:\JAPANO_EAS\japano-fashion-ai-v26-eas-development-build
npx expo start -c --host lan

Nếu Gemini báo HTTP 403 thì key không hợp lệ/chưa đúng loại key cho Generative Language API. App vẫn fallback, không đứng im.
Nếu Gemini báo HTTP 429 thì hết quota/rate limit. App sẽ cooldown rồi fallback local.
Nếu Ollama chậm thì app bỏ qua sau 10 giây và dùng fallback local.
